# AntiSocialize

A meme-powered anti-social-media blocker for dopamine addicts. It guilt-trips you with Vietnamese memes and makes you solve Calculus 1 (Giai tich 1) questions to bypass the block.

## How to Install

1. Open Chrome and go to `chrome://extensions`
2. Enable **Developer mode** in the top right corner.
3. Click **Load unpacked**.
4. Select this folder.
5. The extension will appear in your toolbar!

## Features

- **Calculus Challenges**: Solve limits, integrals, and derivatives to access your sites.
- **Vietnamese Meme Culture**: Enjoy being roasted.
- **Rage Mode**: The more you fail, the worse the UI gets (flashing, shaking, sound effects).
- **Hardcore Mode**: Makes it psychologically harder to disable the extension.

## Tech Stack
- Manifest V3
- Vanilla JS, HTML, CSS
- Web Audio API (No external sound files)
